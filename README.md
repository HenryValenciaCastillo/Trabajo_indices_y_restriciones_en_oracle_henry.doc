## Descripción
Este repositorio contiene la solución práctica para el taller de índices, restricciones y transacciones en Oracle, utilizando el esquema de Recursos Humanos (HR) en una instancia de Oracle Database 21c XE.

### Contenido del repositorio:
* **`Trabajo_Final_HR.sql`**: Script con todas las sentencias DDL y DML ejecutadas durante la práctica.
* **`Documento_Trabajo.pdf`**: Documentación detallada con capturas de pantalla, explicaciones y respuestas a las preguntas teóricas.
